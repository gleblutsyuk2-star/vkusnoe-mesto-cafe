# Вкусное место

Портфолио-сайт московского кафе «Вкусное место» по адресу: Москва, ул. Введенского, 3, корп. 6.

Статический одностраничный сайт на HTML, CSS и JavaScript. Готовая версия находится в каталоге `dist`.

Фотографии взяты из карточки заведения в Яндекс Картах; источники перечислены в `ASSET-SOURCES.md`. Меню и форма бронирования используются только как демонстрация концепции.
